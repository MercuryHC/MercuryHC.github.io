确认同步内容

连接说明与同步文件结构
  • 在网盘同步目录或 NAS 共享盘内新建专用的「个人工作站」目录，再授权给浏览器。请将目录设为本机可用；推荐桌面 Chrome / Edge。浏览器不能直接访问 smb:// 地址，请先在系统挂载。
  • 工作站写入 workstation-data.json，历史版本保存到 workstation-history/。网盘客户端 / NAS 客户端负责继续传输。目录写入完成不代表云端已完成上传；多设备操作前先等待客户端完成同步。
  • 同步文件是含 Markdown 源文的工作站数据包，不是 Obsidian Vault。读取数据包后，选中的 Obsidian 内容会写回已关联的本地 Vault；原文件备份在 .workstation-history/。
  • 文件夹保存会再次比对内容并保留历史，但系统目录没有跨设备原子锁；同一目录请避免两台电脑同时写入。WebDAV 使用 ETag 条件写入；无强 ETag 时停止覆盖。
  • WebDAV 直连需服务器允许本站来源的 CORS，请求方法包括 GET、PUT、MKCOL、PROPFIND、OPTIONS，允许 Authorization、Content-Type、Depth、If-Match、If-None-Match 请求头并暴露 ETag。需使用可信 HTTPS；私网 NAS 可能还需要浏览器的本地网络访问许可。若无法配置，请用同步目录模式，无需公开 NAS 管理端口。
  • Google Drive 目录设置 · 坚果云应用密码 · 飞牛帮助 · 极空间同步功能

GitHub 保留原有按项目、按笔记同步方式。

连接浏览器书签

网页不能直接读取浏览器内部书签。可安装本站提供的 Chrome / Edge 扩展，或使用书签文件导入。

  1. 下载并解压下方扩展包。
  2. 打开浏览器扩展管理页，开启开发者模式，选择「加载已解压的扩展程序」。
  3. 选择含 manifest.json 的文件夹，刷新工作站。
  4. 点击扩展图标，可「立即同步」或开启「自动同步」。自动同步默认关闭。

开启自动同步后，新增、修改、移动、删除会更新本站本机快照；关闭页面期间的更改会在下次打开时读取。扩展只调用书签读取 API，不上传到第三方，不修改原书签。

下载 Chrome / Edge 扩展包

不安装扩展：从浏览器书签管理器导出 HTML，再点击「导入书签文件」。支持保留目录层级、多个来源与搜索。Firefox / Safari 请使用此方式。

连接 Notion

1. 在 Notion 创建内部集成，授予读取内容权限。
2. 在页面的连接设置中，将需要查看的页面共享给该集成。
3. 在下方输入 Integration Token。此连接只读取页面，不修改 Notion 内容。
